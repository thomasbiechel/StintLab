# Schriften für die Slides

Alle drei Familien stehen unter der SIL Open Font License 1.1 (siehe OFL-*.txt) –
frei nutzbar, auch kommerziell, und dürfen mit dem Code weitergegeben werden.

- Barlow Condensed (Titel) – Jeremy Tribby
- Barlow (Text) – Jeremy Tribby
- JetBrains Mono (Zahlen, Achsen) – JetBrains

Quelle: github.com/google/fonts. stintlab/style.py lädt sie beim Import, eine
Installation in Windows ist nicht nötig.
